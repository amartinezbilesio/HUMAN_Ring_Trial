NAPS chromExtract — re-extraction producer for 4_rt_alignment

Goal

Re-extract NAPS anchor apex RTs by chromExtract at the theoretical m/z (from compound formula) plus an RT-seeded window, with cross-lab propagation for gaps. This replaces the xcms-based per-lab naps.csv as the alignment input.

Why: the xcms-derived NAPS RTs in 1_preprocessing/{lab}/HE/naps.csv have systematic problems — icl is missing C1–C3 entirely (xcms didn’t pick them) and cembio-pos has a few replicates with catastrophic outliers (wrong-peak picks). chromExtract at theoretical m/z lets us recover those because we’re not relying on xcms to find a feature first — we ask: “is there a peak at this m/z near this RT?”.

Output: 5_downstream_analysis/object/naps_chrom_metrics.csv keyed on (lab, polarity, anchor_n, replicate, source) with columns apex_rt, xicFwhm, maxIntensity, areaUnderTic.

Source semantics:

  • source = "own" — rt_center came from the lab’s own naps.csv for that (anchor, replicate).
  • source = "consensus" — rt_center came from cross-lab median (this replicate’s slot was NA in the lab’s CSV; propagated).

3. Build seed rt_center per (lab, polarity, anchor, replicate)

Read each lab’s existing naps.csv to pull the per-replicate RT column. Then compute cross-lab consensus per (polarity, anchor) (median across labs of per-lab median RT) for the propagation fallback.

Code 
read_naps_long <- function(lab) {
  df <- read.csv(here("1_preprocessing", lab, "HE", "naps.csv"),
                 stringsAsFactors = FALSE, check.names = FALSE) |>
    .drop_empty_cols()
  df$anchor_n <- suppressWarnings(as.integer(
    gsub("^C(\\d+).*", "\\1", df$Name)))
  pos_cols <- grep("^NAPS_POS_", names(df), value = TRUE)
  neg_cols <- grep("^NAPS_NEG_", names(df), value = TRUE)
  bind_rows(
    df |> select(anchor_n, all_of(pos_cols)) |>
      pivot_longer(all_of(pos_cols), names_to = "rep_col",
                   values_to = "rt_csv") |>
      mutate(polarity = "pos",
             replicate = as.integer(gsub("^NAPS_POS_", "", rep_col))),
    df |> select(anchor_n, all_of(neg_cols)) |>
      pivot_longer(all_of(neg_cols), names_to = "rep_col",
                   values_to = "rt_csv") |>
      mutate(polarity = "neg",
             replicate = as.integer(gsub("^NAPS_NEG_", "", rep_col)))
  ) |>
    transmute(lab = lab, polarity, anchor_n, replicate, rt_csv)
}

naps_csv_long <- bind_rows(lapply(labs, read_naps_long)) |>
  filter(!is.na(anchor_n))

# Cross-lab consensus per (polarity, anchor) = median of per-lab medians
consensus_rt <- naps_csv_long |>
  filter(!is.na(rt_csv)) |>
  group_by(lab, polarity, anchor_n) |>
  summarise(rt_lab_med = median(rt_csv), .groups = "drop") |>
  group_by(polarity, anchor_n) |>
  summarise(consensus_rt = median(rt_lab_med),
            n_labs       = n(),
            .groups = "drop")

# Seed table: own rt_csv if present, else consensus_rt
seed_table <- naps_csv_long |>
  left_join(consensus_rt, by = c("polarity", "anchor_n")) |>
  mutate(rt_center = coalesce(rt_csv, consensus_rt),
         source    = ifelse(is.na(rt_csv), "consensus", "own")) |>

5. chromExtract — single wide pass (±60 s)

The legacy two-pass design (tight ±10 s pass 1, fallback ±60/+20 s pass 2) was replaced after audit showed it systematically missed real peaks for icl pos NAPS C10: a 5 × 10⁵-count peak sits 11 s before the consensus RT; the pass-1 ±10 s window excluded it and the pass-2 retry never fired because peakBoundary() returned a 386-count noise spike inside the tight window. A single wide extraction + SNR-aware picker (§6) avoids that failure mode.

6. SNR-aware peak picking

We use the same picker as sirius_annotation_all_ms2.qmd §7.6 (with the bottom-half-tail noise estimate). For NAPS the SNR/shape/absolute- floor guards almost never trigger — NAPS standards are concentrated and easily above detection — but having them present means the few genuine NAPS extraction failures (e.g. an injection where the column didn’t elute the standard at all) get cleanly flagged rather than fabricated.

Code 
extract_one <- function(rt, intensity, rt_prior,
                        apex_search_pad = 20,
                        tail_pad        = 25,
                        snr_threshold   = 5,
                        abs_min_counts  = 30) {
  ok <- !is.na(intensity); rt <- rt[ok]; intensity <- intensity[ok]
  if (length(rt) < 5L)
    return(list(detection = "no_data",
                apex_rt = NA_real_, maxIntensity = NA_real_,
                areaUnderTic = NA_real_, xicFwhm = NA_real_,
                snr = NA_real_, baseline = NA_real_, noise = NA_real_,
                n_scans_in_shape = 0L))
  sm <- as.numeric(stats::filter(intensity, rep(1, 3) / 3, sides = 2))
  sm[is.na(sm)] <- intensity[is.na(sm)]
  search_idx <- which(rt >= rt_prior - apex_search_pad &
                      rt <= rt_prior + apex_search_pad)
  if (!length(search_idx))
    return(list(detection = "no_data",
                apex_rt = NA_real_, maxIntensity = NA_real_,
                areaUnderTic = NA_real_, xicFwhm = NA_real_,
                snr = NA_real_, baseline = NA_real_, noise = NA_real_,
                n_scans_in_shape = 0L))
  apex_local <- search_idx[which.max(intensity[search_idx])]
  apex_rt    <- rt[apex_local]; apex_int <- intensity[apex_local]
  tail_idx <- which(abs(rt - apex_rt) > tail_pad)
  if (length(tail_idx) < 10L) {
    n <- length(rt); tail_idx <- c(seq_len(round(0.25 * n)),
                                    (n - round(0.25 * n) + 1L):n)
  }
  tail_int <- intensity[tail_idx]
  tail_low <- tail_int[tail_int <= quantile(tail_int, 0.5, na.rm = TRUE)]
  baseline <- median(tail_low, na.rm = TRUE)
  noise_mad <- mad(tail_low, na.rm = TRUE)
  q15 <- as.numeric(quantile(tail_low, 0.15, na.rm = TRUE))
  q85 <- as.numeric(quantile(tail_low, 0.85, na.rm = TRUE))
  raw_noise <- max(noise_mad, (q85 - q15) / 2, na.rm = TRUE)
  noise_at_floor <- !is.finite(raw_noise) || raw_noise <= 0
  noise <- max(raw_noise, 1, na.rm = TRUE)
  snr   <- (apex_int - baseline) / noise
  v_idx <- tryCatch(MsCoreUtils::valleys(sm), error = function(e) integer(0))
  if (length(v_idx) >= 2L) {
    left  <- suppressWarnings(max(v_idx[v_idx <= apex_local], na.rm = TRUE))
    right <- suppressWarnings(min(v_idx[v_idx >= apex_local], na.rm = TRUE))
    if (!is.finite(left))  left  <- 1L
    if (!is.finite(right)) right <- length(rt)
  } else {
    left <- apex_local; right <- apex_local
    while (left  > 1L         && sm[left  - 1L] > baseline + noise) left  <- left  - 1L
    while (right < length(rt) && sm[right + 1L] > baseline + noise) right <- right + 1L
  }
  pk_rt <- rt[left:right]; pk_int <- intensity[left:right]
  area  <- if (length(pk_rt) >= 2L)
             sum(diff(pk_rt) * (pk_int[-1] + pk_int[-length(pk_int)]) / 2)
           else NA_real_
  hm    <- (apex_int - baseline) / 2 + baseline
  above <- which(pk_int >= hm)
  fwhm  <- if (length(above) >= 2L) diff(range(pk_rt[above])) else NA_real_
  nb_lo <- max(1L, apex_local - 2L); nb_hi <- min(length(rt), apex_local + 2L)
  n_shape <- sum(intensity[nb_lo:nb_hi] >= 0.3 * apex_int, na.rm = TRUE)
  detection <- if (apex_int <= baseline) "below_detection"
               else if (snr < snr_threshold) "below_detection"
               else if (n_shape < 2L) "below_detection"
               else if (noise_at_floor && apex_int < abs_min_counts) "below_detection"
               else "detected"
  list(detection = detection, apex_rt = apex_rt,
       maxIntensity = if (detection == "detected") apex_int else NA_real_,
       areaUnderTic = if (detection == "detected") area     else NA_real_,
       xicFwhm     = if (detection == "detected") fwhm     else NA_real_,
       snr = snr, baseline = baseline, noise = noise,
       n_scans_in_shape = n_shape)
}

Notes

  • 4_rt_alignment.qmd should now read naps_chrom_metrics.csv in preference to the per-lab naps.csv files. The structure is long-form already ((lab, polarity, anchor_n, replicate, source, apex_rt)), so the existing naps_long build in §P2.1 collapses to a single read.
  • source distinguishes own-seeded vs consensus-propagated rows. Downstream filtering on source == "own" reproduces the xcms-replacement view; including consensus rows is the propagation-augmented view.
  • The QC scatter / SD plots above are the gate: if the new chromExtract SDs are not noticeably tighter than the original xcms ones for the problematic labs (cembio-pos, icl), revisit the seed propagation or the m/z tolerance before trusting the alignment downstream.
