Annotated abundance ICC and cross-lab analysis (Phase 3 consumer)

Goal

Consume annotation_chrom_metrics_normalized.csv produced by 5_normalization.qmd and compute the cross-lab reproducibility analyses:

  • §P3.5 — Bulk ICC ladder under five strategies × two metrics × two compound-set policies (Strict / Inclusive).
  • §P3.5.c — Side analysis on the quorum-3+/4 compound set.
  • §P3.6 — Pairwise ICC across all 6 lab pairs, including the Agilent same-platform pair as the ceiling reference.
  • §P3.6.b–g — Per-lab diagnostic chunks: rank/log correlation vs the cross-lab consensus, leave-one-out consensus, per-compound hmgu deep-dive, 3-lab ICC excluding hmgu, and pairwise per-compound correlations.
  • §P3.7 — Per-(compound, mixture) cross-lab CV distribution.

The producer file builds the normalized annotated table. This file reads it and asks the methodological + reproducibility questions.

P3.5 ICC ladder under alignment + normalization strategies

Data level: Annotated Signal (same as 8_data_level_progression.qmd’s Annotated row). Per-(lab, mixture, polarity) bulk metric = sum of an abundance column over the well-detected set.

Two abundance metrics scored in parallel:

  • maxIntensity — sum of peak heights. Scan-rate robust.
  • areaUnderTic — sum of peak areas. Standard TIC bulk; directly comparable to 2_global’s Annotated TIC ICC.

Two compound-set policies:

  • Strict — compounds where all 4 labs are in the anchor range. Lab-balanced and trustworthy on every row; loses 39% of well-detected.
  • Inclusive — all well-detected compounds. For the lab(s) where alignment failed, the row falls back to factor_global. Keeps the full set; the unaligned lab(s) get a weaker correction.

make_bulk_for <- function(metric_col, mode = c("strict", "inclusive")) {
  mode       <- match.arg(mode)
  global_col <- paste0(metric_col, "_global")
  decile_col <- paste0(metric_col, "_decile")
  loess_col  <- paste0(metric_col, "_loess")

  factor_set <- if (mode == "strict") ann_well_aligned else ann_well
  set_label  <- if (mode == "strict")
                  "Strict (4/4 labs aligned, n = strict_n)"
                else
                  "Inclusive (all well-detected, n = incl_n, global fallback)"

  bulk_raw <- ann_well |>
    group_by(lab, mixture, polarity) |>
    summarise(bulk = sum(.data[[metric_col]], na.rm = TRUE),
              .groups = "drop") |>
    mutate(strategy = "Raw")

  bulk_aligned <- if (mode == "strict") {
    ann_well_aligned |>
      group_by(lab, mixture, polarity) |>
      summarise(bulk = sum(.data[[metric_col]], na.rm = TRUE),
                .groups = "drop") |>
      mutate(strategy = "Aligned")
  } else NULL

  bulk_norm <- factor_set |>
    mutate(int_global = .data[[global_col]],
           int_decile = coalesce(.data[[decile_col]], .data[[global_col]]),
           int_loess  = coalesce(.data[[loess_col]],  .data[[global_col]])) |>
    group_by(lab, mixture, polarity) |>
    summarise(Global = sum(int_global, na.rm = TRUE),
              Decile = sum(int_decile, na.rm = TRUE),
              LOESS  = sum(int_loess,  na.rm = TRUE),
              .groups = "drop") |>
    pivot_longer(c(Global, Decile, LOESS),
                 names_to = "strategy", values_to = "bulk")

  bind_rows(bulk_raw, bulk_aligned, bulk_norm) |>
    mutate(metric = metric_col, alignment_set = set_label)
}

    }))
  }))
