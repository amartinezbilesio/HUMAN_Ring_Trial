Confidence tiering — populate annotation_identity.csv (Phase 5)

Goal

Populate the confidence_tier column in annotation_identity.csv, overwriting the P1 "unfiltered" placeholder with A / B / C / D tiers based on:

  1. COSMIC score (within-lab confidence): the producer’s confidenceExactMatch from SIRIUS. Each lab assigns a score per annotated compound; we use the max across labs per (mixture, compound, polarity) so a compound flagged confidently by any lab gets credit.

  2. MS1-RT concordance (between-lab confidence): SD of P2-aligned apex_rt across labs that have a measurable peak (either own = SIRIUS-annotated, or consensus = MS1-rescued from cross-lab median). Small SD → labs agree on chromatographic position → high cross-lab confidence in the identification.

The CANONICAL_SCHEMAS.md contract says this column is overwritten in place. Downstream consumers (9_per_compound_diagnostics.qmd, 7_icc_reproducibility.qmd) can then filter by confidence_tier %in% c("A", "B") to restrict to confident identifications.

Tier definition

  • A: COSMIC ≥ 0.5 and aligned-RT SD ≤ 3 s. Both axes strong.
  • B: COSMIC ≥ 0.5 and aligned-RT SD ≤ 10 s, or COSMIC ≥ 0.1 and aligned-RT SD ≤ 3 s. One axis strong, one marginal.
  • C: anything else with both axes computable (some weight on both). Treat as low confidence.
  • D: missing one axis (NA COSMIC or undetermined RT SD because <2 labs detect / aligned). Treat as not-defensible.

Thresholds are at the top of the setup chunk; the producer report shows tier counts, so they can be tuned by editing and re-running.

cosmic_max <- identity_df |>

3. RT-concordance axis: SD of aligned_rt across labs

Code 
# Per (mixture, compound, polarity), collapse to one apex_rt per lab
# (max-maxIntensity peak across adducts/sources), then SD across labs.
rt_concordance <- chrom_norm |>
  filter(!is.na(aligned_rt), !is.na(maxIntensity), maxIntensity > 0) |>
  group_by(mixture, compound, polarity, lab) |>
  slice_max(maxIntensity, n = 1, with_ties = FALSE) |>
  ungroup() |>
  group_by(mixture, compound, polarity) |>
  summarise(rt_n_labs = n_distinct(lab),
            rt_sd_aligned = if (n_distinct(lab) >= min_labs_for_rt_sd)
                               sd(aligned_rt, na.rm = TRUE)
                            else NA_real_,
            .groups = "drop")

cat("Tuples with computable RT SD (>=", min_labs_for_rt_sd, "labs aligned): ",
    sum(!is.na(rt_concordance$rt_sd_aligned)), " / ", nrow(rt_concordance),
    "\n", sep = "")
Tuples with computable RT SD (>=2labs aligned): 392 / 438

4. Assemble + apply tier logic

Code 
combined_axes <- cosmic_max |>
  full_join(rt_concordance,
            by = c("mixture", "compound", "polarity")) |>
  mutate(tier = case_when(
    is.na(cosmic_max) | is.na(rt_sd_aligned)                             ~ "D",
    cosmic_max >= cosmic_strong   & rt_sd_aligned <= rt_sd_strong        ~ "A",
    cosmic_max >= cosmic_strong   & rt_sd_aligned <= rt_sd_marginal      ~ "B",
    cosmic_max >= cosmic_marginal & rt_sd_aligned <= rt_sd_strong        ~ "B",
    TRUE                                                                  ~ "C"))

5. Overwrite confidence_tier in annotation_identity.csv

Per the CANONICAL_SCHEMAS.md contract, confidence_tier is updated in place. The same (mixture, compound, polarity) tuple gets the same tier across all lab rows.

Code 
identity_df_tiered <- identity_df |>
  select(-confidence_tier) |>
  left_join(combined_axes |>
              select(mixture, compound, polarity, tier),
            by = c("mixture", "compound", "polarity")) |>
  rename(confidence_tier = tier) |>
  # Defensive: any join misses default back to D so the column has no NAs.
  mutate(confidence_tier = coalesce(confidence_tier, "D"))

stopifnot(all(c("confidence_tier") %in% names(identity_df_tiered)))
stopifnot(nrow(identity_df_tiered) == nrow(identity_df))

# Re-order columns to match the original schema (CANONICAL_SCHEMAS.md).
identity_df_tiered <- identity_df_tiered |>
  select(mixture, lab, compound, inchikey_2d, polarity,
         best_formula_rank, best_structure_rank, adducts,
         molecularFormula, expected_formula, expected_inchikey,
         mz_observed, confidenceExactMatch, confidenceApproxMatch,
         confidence_tier)

write.csv(identity_df_tiered,
          file.path(producer_dir, "annotation_identity.csv"),
          row.names = FALSE)

Notes

  • Re-running this file is idempotent — it always recomputes tiers from the same axes and overwrites the column.
  • If thresholds change (top of setup), the producer’s tier counts in this report show whether you’re in a sensible regime. Tier A should not be empty; if it is, thresholds are too strict.
  • confidence_tier = "D" rows are compounds where one of the two axes could not be computed (e.g. < 2 labs detect → no RT SD; COSMIC is NA). These are not “low confidence” so much as “not-defensible”; downstream code should treat them as “not-yet-graded” rather than filtering them out as bad.
  • Consumers that previously read annotation_identity.csv with filter(confidence_tier == "unfiltered") will now see no rows (placeholder gone) — switch them to filter(confidence_tier %in% c("A", "B")) for confident-only, or remove the filter to keep all.
