Data-level progression: Full → Detected → Annotated → Consensus

Introduction

The same 19 mixtures × 4 labs × 2 polarities are observable at four different data levels, each built by a different stage of the processing pipeline:

Level Built by Feature space Per sample summary
Full mzML, no peak detection all MS1 ions TIC, BPC
Detected xcms (per-lab, per-sample peak picking) per-injection detected peaks TIC, BPC restricted to detected ions
Annotated SIRIUS MS2 + SNR-aware chromExtract the spike-in panel (~250 (mix × compound) tuples detected in ≥1 lab) sum/max of maxIntensity over the panel
Consensus 2_consensus_peaks.qmd cross-lab feature matching 3 490 (NAPS-aligned) / 1 787 (Phase 5 legacy cache — see Cache vintage note in §5) features matched in all 4 labs sample × consensus-peak matrix

This file asks one question: does each successive layer recover biological signal from technical variance? The answer is yes — see the Phase 1 variance decomposition and PCA progression for the headline story, and the Phase 5 Consensus-peak analysis for the per-peak picture on the broader feature space (1.8k features vs ~250 in Annotated).

Other axes of the analysis live in dedicated files:

  • Normalization strategies (Global / Decile / LOESS / NAPS) → 5_normalization.qmd + 7_icc_reproducibility.qmd
  • Cross-lab ICC ladder, pairwise reproducibility, 3-lab subset (no hmgu), Agilent ceiling → 7_icc_reproducibility.qmd
  • NAPS RT alignment → 4_rt_alignment.qmd
  • Per-compound identity / RT / abundance / m/z diagnostics → 9_per_compound_diagnostics.qmd
  • Confidence tiering (A / B / C / D) → 6_confidence_tier.qmd

Data: 19 standard mixtures (HUMAN endosome) from 4 labs with harmonized LC systems. No technical replicates; lab identity is confounded with instrument platform.

Metrics Definition

Three main chromatographic metrics:

  • TIC: Sum of all ion intensities
  • BPC: Max intensity per scan

Three data levels (least → most processed):

  • Full Signal: raw profile including baseline (bpc_full / tic_full)
  • Detected Signal: peaks from centWave; isolates compound signal from baseline (bpc_detect / tic_detect)
  • Annotated Signal: derived from annotation_chrom_metrics.csv (SIRIUS producer) restricted to (mixture, compound) pairs with non-NA maxIntensity in all 4 labs at that polarity (recomputed each render — the “well-detected” set, not hardcoded). Per-sample bulk: tic = sum(areaUnderTic); bpc = max(maxIntensity). Polarity is collapsed per-side so each polarity has its own well-detected set.

Two polarities: Positive and Negative ionization modes.

compute_metrics <- function(polarity, polarity_name, data_level = "full") {
  if (data_level == "full") {
    load(file.path(base_path, "object/bpc_full.RData"))
    bpc <- bpc_full[bpc_full$polarity == polarity]
    load(file.path(base_path, "object/tic_full.RData"))
    tic <- tic_full[tic_full$polarity == polarity]
  } else {
    load(file.path(base_path, "object/bpc_detect.RData"))
    bpc <- bpc_detect[bpc_detect$polarity == polarity]
    load(file.path(base_path, "object/tic_detect.RData"))
    tic <- tic_detect[tic_detect$polarity == polarity]
  }

  data.frame(
    lab = bpc$lab,
    mixture = bpc$mixture,
    polarity = polarity_name,
    bpc = vapply(intensity(bpc), sum, numeric(1), na.rm = TRUE),
    tic = vapply(intensity(tic), sum, numeric(1), na.rm = TRUE)
  ) %>%
    left_join(setup_simplified, by = "lab") %>%
    mutate(data_level = ifelse(data_level == "full", "Full Signal", "Detected Signal")) %>%
    group_by(lab, polarity) %>%
    mutate(
      median_bpc = median(bpc, na.rm = TRUE),
      median_tic = median(tic, na.rm = TRUE),
      bpc_norm = bpc / median_bpc,
      tic_norm = tic / median_tic
    ) %>%
    ungroup()
}

compute_metrics_annotated <- function(polarity, polarity_name) {
  pol_str <- if (polarity == 1L) "pos" else "neg"

  # mixture forced to character — read.csv would otherwise coerce quoted
  # "2.10" → 2.1 (numeric), silently colliding with mixture "2.1".
  chrom <- read.csv(file.path(producer_dir, "annotation_chrom_metrics.csv"),
                    stringsAsFactors = FALSE,
                    colClasses = c(mixture = "character"))

  well_detected <- chrom %>%
    filter(polarity == pol_str, !is.na(maxIntensity)) %>%
    distinct(mixture, compound, lab) %>%
    count(mixture, compound) %>%
    filter(n == 4L) %>%
    select(mixture, compound)

  bulk <- chrom %>%
    filter(polarity == pol_str, !is.na(maxIntensity)) %>%
    inner_join(well_detected, by = c("mixture", "compound")) %>%
    group_by(lab, mixture, compound) %>%
    slice_max(maxIntensity, n = 1, with_ties = FALSE) %>%
    ungroup() %>%
    group_by(lab, mixture) %>%
    summarise(bpc = max(maxIntensity, na.rm = TRUE),
              tic = sum(areaUnderTic, na.rm = TRUE),
              .groups = "drop")

  data.frame(
    lab = bulk$lab, mixture = bulk$mixture,
    polarity = polarity_name,
    bpc = bulk$bpc, tic = bulk$tic
  ) %>%
    left_join(setup_simplified, by = "lab") %>%
    mutate(data_level = "Annotated Signal") %>%
    group_by(lab, polarity) %>%
    mutate(
      median_bpc = median(bpc, na.rm = TRUE),
      median_tic = median(tic, na.rm = TRUE),
      bpc_norm   = bpc / median_bpc,
      tic_norm   = tic / median_tic
    ) %>%
    ungroup()
}

1.2 Variance Decomposition: Quantifying the Problem

Let’s run linear models to evaluate mixture effects and batch effects. The goal is to quantify how much of the variance is due to lab vs mixture. We use ANOVA to aggregate coefficients into Sum of Squares (SS), which quantifies the relative power of each factor.

prepare_pca_tic <- function(data_level, polarity_int) {
  if (data_level == "full") {
    load(file.path(base_path, "object/tic_full.RData"))
    chr_data <- tic_full[tic_full$polarity == polarity_int]
  } else {
    load(file.path(base_path, "object/tic_detect.RData"))
    chr_data <- tic_detect[tic_detect$polarity == polarity_int]
  }

  int_list <- intensity(chr_data); rt_list <- rtime(chr_data)
  all_rts  <- unlist(rt_list)
  rt_grid  <- seq(min(all_rts, na.rm = TRUE),
                  max(all_rts, na.rm = TRUE), length.out = 500)

  int_matrix <- t(sapply(seq_along(int_list), function(i) {
    approx(rt_list[[i]], int_list[[i]], xout = rt_grid,
           method = "linear", rule = 2)$y
  }))
  rownames(int_matrix) <- paste0(chr_data$lab, "_", chr_data$mixture)
  colnames(int_matrix) <- paste0("RT_", round(rt_grid, 1))

  list(data = int_matrix,
       meta = data.frame(sample  = rownames(int_matrix),
                         lab     = chr_data$lab,
                         mixture = chr_data$mixture))
}

# Annotated: sample × compound maxIntensity, restricted to the
# well-detected set (same definition as the bulk Annotated metric above).
prepare_pca_annotated <- function(polarity_int) {
  pol_str <- if (polarity_int == 1L) "pos" else "neg"
  chrom <- read.csv(file.path(producer_dir, "annotation_chrom_metrics.csv"),
                    stringsAsFactors = FALSE,
                    colClasses = c(mixture = "character"))

  well_detected <- chrom |>
    filter(polarity == pol_str, !is.na(maxIntensity)) |>
    distinct(mixture, compound, lab) |>
    count(mixture, compound) |>
    filter(n == 4L) |>
    select(mixture, compound)

  wide <- chrom |>
    filter(polarity == pol_str, !is.na(maxIntensity)) |>
    inner_join(well_detected, by = c("mixture", "compound")) |>
    group_by(lab, mixture, compound) |>
    slice_max(maxIntensity, n = 1, with_ties = FALSE) |>
    ungroup() |>
    mutate(sample = paste0(lab, "_", mixture)) |>
    select(sample, compound, maxIntensity, lab, mixture) |>
    pivot_wider(names_from = compound, values_from = maxIntensity,
                values_fill = 0) |>
    arrange(sample)

  data_mat <- wide |> select(-sample, -lab, -mixture) |> as.matrix()
  rownames(data_mat) <- wide$sample
  list(data = data_mat, meta = wide |> select(sample, lab, mixture))
}

# Consensus: sample × consensus-peak matrix from 3_peak_feature output.
prepare_pca_consensus <- function(polarity_int) {
  pk_metrics <- read.csv(file.path(base_path,
                                   "object/peak_metrics_detected_all4labs.csv"),
                         stringsAsFactors = FALSE,
                         colClasses = c(mixture = "character"))
  wide <- pk_metrics |>
    filter(as.integer(polarity) == polarity_int) |>
    mutate(sample = paste0(lab, "_", mixture)) |>
    select(sample, consensus_id, areaUnderTic, lab, mixture) |>
    pivot_wider(names_from = consensus_id, values_from = areaUnderTic,
                values_fill = 0, names_prefix = "peak_") |>
    arrange(sample)

  data_mat <- wide |> select(starts_with("peak_")) |> as.matrix()
  rownames(data_mat) <- wide$sample
  list(data = data_mat, meta = wide |> select(sample, lab, mixture))
}

# Run prcomp, drop zero-variance columns so scale.=TRUE doesn't error.
pca_scores_df <- function(pca_list, polarity_label, transform_fn = identity) {
  X <- transform_fn(pca_list$data)
  keep <- apply(X, 2, function(z) is.finite(var(z)) && var(z) > 0)
  res <- prcomp(X[, keep, drop = FALSE], scale. = TRUE, center = TRUE)
  var_expl <- (res$sdev^2 / sum(res$sdev^2)) * 100
  list(scores = data.frame(PC1 = res$x[, 1], PC2 = res$x[, 2],
                           lab = pca_list$meta$lab,
                           mixture = pca_list$meta$mixture,
                           polarity = polarity_label),
       var_expl = var_expl)
}

          legend.position = "right")
}

Phase 5: Peak Feature Analysis — Consensus Peaks

This phase extends the global analysis by incorporating peak-level metrics computed from EICs of consensus peaks detected across all 4 laboratories. This provides a more refined view of inter-lab reproducibility at the individual peak level.

Scope note. Phase 5 reads peak_metrics_detected_all4labs.csv from 2_consensus_peaks.qmd, which matches xcms-detected peaks across labs without any spike-in identity. It is independent of the SIRIUS producer cluster-RT algorithm — re-running the producer does not require re-rendering 2_consensus_peaks.qmd. Phase 5 answers a different question: “for the same chromatographic feature detected in all 4 labs, how reproducible is the peak shape / intensity?” — the flip side of the Annotated row, where Phase 5 measures detection-level agreement and the Annotated row measures identity-level abundance.

Cache vintage. The peak_metrics table currently on disk was produced by 2_consensus_peaks.qmd under raw-RT matching (1 787 4-lab features). The current 2_consensus_peaks.qmd uses NAPS-aligned matching with raw-RT fallback, which recovers ~3 490 4-lab features. Refreshing Phase 5 to the aligned-matched feature set requires loading sp_full.RData (~ 10 GB) to re-extract EICs and is deferred. The Annotated-level and Annotated-level-derived ICC numbers (reported in 7_icc_reproducibility.qmd) are unaffected.

5.3 Peak Metric Distributions Across Labs

The following metrics are computed for each EIC from the filtered consensus peaks:

  • Peak Width: Time span (seconds) between the detected peak boundaries. Reflects chromatographic resolution and column performance.
  • FWHM (Full Width at Half Maximum): Width of the peak at half its maximum intensity. A narrower, more symmetric measure of peak shape than peak width.
  • Signal-to-Noise Ratio (SNR): Ratio of peak maximum intensity to the estimated baseline. Higher SNR indicates a cleaner, more confident detection.

5.4 Inter-Lab Variability for Consensus Peaks

For each consensus peak (detected in all 4 labs), we compute the coefficient of variation (CV = standard deviation / mean) of each metric across the 4 labs. CV is inherently scale-normalized: it measures relative spread regardless of absolute intensity differences, so no prior normalization of intensity metrics is needed.

  • CV < 0.3 (30%): Good reproducibility
  • CV 0.3–0.5: Moderate variability
  • CV > 0.5: High variability

IQR (Interquartile Range): the difference between the 75th and 25th percentiles of the CV distribution, measuring the spread of the middle 50% of values.

5.4.1 CV Summary Table

Summary

This file shows the data-level progression story:

  1. Lab variance dominates raw data. At the Full Signal level, 97–100 % of TIC variance is lab-attributable. PCA shape clusters (lab dominates), mixture colours scattered.
  2. Peak detection recovers some biology. Detected Signal PCA shape clusters loosen, colour grouping emerges. xcms peak picking strips most of the lab-specific background.
  3. Annotation concentrates the biology further. Annotated PCA (sample × compound maxIntensity) tightens mixture clusters; lab spread within each mixture shrinks. SIRIUS-keyed features carry identity-aware abundance.
  4. Consensus peaks deliver the cleanest picture. The cross-lab matched peak set (~1.8 k features) gives tight per-mixture clusters in PCA + UMAP — same-mixture points across all four labs sit together. Per-peak inter-lab CV distribution shows the broader feature space behaves like the spike-in panel.

For the quantitative reproducibility numbers (ICC ladder, pairwise ICC, same-platform Agilent ceiling, 3-lab subset), see 7_icc_reproducibility.qmd. For the normalization strategy comparison, see 5_normalization.qmd + 7_icc_reproducibility.qmd. For the RT alignment, see 4_rt_alignment.qmd. For the per-compound diagnostics, see 9_per_compound_diagnostics.qmd.
